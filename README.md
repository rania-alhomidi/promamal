# نظام تقييم الطلاب في المعمل

تطبيق Flask بسيط لإدارة الطلاب وتقييم أدائهم داخل المعمل باستخدام QR Code.

## المميزات
- تسجيل دخول مشرف فقط
- إضافة طلاب مع صورة ورقم طالب
- إنشاء QR Code لكل طالب
- تقييم الطالب من قبل المشرف
- تسجيل الحوادث والضرر
- عرض تفاصيل الطالب وسجل التقييمات
- تصدير التقارير إلى Excel و PDF
- واجهة عنابية مائلة للأحمر

## التشغيل

1. تثبيت الحزم:
   ```bash
   pip install -r requirements.txt
   ```

2. تشغيل التطبيق:
   ```bash
   python app.py
   ```

3. افتح المتصفح:
   ```text
   http://127.0.0.1:5000/login
   ```

## بيانات الدخول الافتراضية
- اسم المستخدم: admin
- كلمة المرور: admin123

## ملاحظات
- لا يوجد تسجيل ذاتي للطلاب
- لا يوجد مدير
- لا توجد إدارة للأدوات
- يوجد QR لكل طالب فقط
- عند مسح QR يتم فتح صفحة الطالب مباشرة
